MY CAR MANAGER v6 — iPhone / Safari

ไฟล์ในชุดนี้: index.html, manifest.json, icon.svg, sw.js

ติดตั้งใช้งานบน iPhone
1) แตกไฟล์ ZIP ในแอป Files จะได้โฟลเดอร์ MY_CAR_MANAGER
2) อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยังโฮสต์เว็บไซต์ที่รองรับ HTTPS (เช่น เว็บโฮสต์หรือ static hosting) โดยคงโครงสร้างไฟล์เดิม
3) เปิด URL ของ index.html ด้วย Safari
4) แตะปุ่ม Share (สี่เหลี่ยมมีลูกศรขึ้น)
5) เลือก Add to Home Screen / เพิ่มไปยังหน้าจอโฮม
6) ตั้งชื่อ MY CAR MANAGER แล้วแตะ Add / เพิ่ม
7) เปิดแอปจากไอคอนบนหน้าจอโฮม

หมายเหตุ: การติดตั้ง PWA และ Service Worker ต้องใช้ HTTPS (ยกเว้น localhost) ไม่สามารถติดตั้ง PWA จากการเปิดไฟล์ HTML โดยตรงใน Files ได้
ข้อมูลรถถูกเก็บในพื้นที่จัดเก็บของเบราว์เซอร์บนอุปกรณ์ ควรกดสำรองข้อมูลเป็นระยะ และอย่าล้าง Website Data ก่อนสำรองข้อมูล


เวอร์ชัน 7: ตัดเมนูแถบล่างออกแล้ว ใช้แถบเมนูแนวนอนด้านบนแทน แตะชื่อหมวดหมู่เพื่อเปิดหน้าได้โดยตรง เลื่อนแถบเมนูซ้าย-ขวาเพื่อดูรายการทั้งหมด
